# @axi/scaffold-feature-hooks

## Role

Optional shared hooks extension modules for generated applications.

## Allowed Workspace Dependencies

- `@axi/scaffold-kit`

## Owns

- reusable hooks starters
- hook index files
- hook tests and hook docs

## Must Not Do

- depend on `feature-ui`, `feature-theme`, or any foundation package
- own token generation
- own CLI runtime logic
