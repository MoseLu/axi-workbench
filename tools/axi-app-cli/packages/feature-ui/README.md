# @axi/scaffold-feature-ui

## Role

Optional UI primitives and style-system extension modules.

## Allowed Workspace Dependencies

- `@axi/scaffold-kit`

## Owns

- UI component starter set
- style-system extension files
- component-facing tests and docs

## Must Not Do

- depend on `feature-theme` or `foundation-design`
- become the token source of truth
- own runtime policy
