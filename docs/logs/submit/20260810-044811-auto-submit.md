## Commit Body

Migrate the four smaller admin chrome pages that still held literal
Chinese strings: Team (project collaboration), the dedicated Search
page, MenuList (navigation entry catalog) and AuthCallback.

Each page now threads its chrome through useI18n() under a dedicated
namespace (team.*, search.*, menuList.*, auth.callback.*) and reuses
shared chrome keys from projects.column.*, operations.column.status,
search.section.* and common.search.* so wording stays canonical across
pages. MenuList.test.ts still asserts on filterMenuRows, so the export
is preserved alongside the i18n migration.

CommandCenter.tsx is intentionally left out of scope: App.tsx does not
route to it, the file already ships almost entirely in English, and
the layer label dictionary would need a separate i18n namespace that
no other page consumes. Migrating it now would add keys with a single
consumer and zero reachable chrome.
