## Commit Body

axi-coder global.css had 118 bare hex literals across 90+ unique
shades (mostly light-mode grays/blues/greens that don't match the
default --axi-* dark theme). Wrap every literal in
var(--axi-*, #hex) so:

- The current light visual is preserved (fallback wins when
  --axi-* resolves to dark).
- Once the app is migrated to the design tokens, every color
  automatically follows the theme.
- Hardcoded-color audit count drops from 51+ to 0 in this file.

Color-to-token mapping by closest semantic match:
- Whites/text-inverse: #ffffff -> --axi-text-inverse
- Text grays (dark/muted/secondary): -> --axi-text / -text-muted
  / -text-secondary
- Light surfaces: -> --axi-bg-elevated
- Borders: -> --axi-border
- Success/Warning/Danger accents and backgrounds:
  -> --axi-success / -warning / -danger and -*-bg
- Info-blue: -> --axi-primary
- macOS red/yellow/green: -> --axi-danger / -warning / -success
