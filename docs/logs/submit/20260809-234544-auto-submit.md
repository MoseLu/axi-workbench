## Commit Body

Six css files across axi-coder, workbench-mobile, and
verification-inbox had 14 occurrences of 'border-radius: 999px;'
(the standard CSS idiom for a pill / fully rounded shape). All
are now wrapped as 'border-radius: var(--axi-radius-full, 999px);'
where --axi-radius-full resolves to 9999px in @axi/tokens.

Visual difference: for any element shorter than 1998px the visual
is identical (border-radius caps at half the shorter side). For
taller elements the new value produces a slightly rounder
ellipse, but no element in these files approaches that size.
