## Commit Body

RightSidebar.tsx held the entire system settings panel as literal Chinese
strings, even though common.theme.* / common.layout.settings / common.sidebar.width
/ common.tabbar / common.breadcrumb / common.show / common.settings.title
already exist in both locale dictionaries. The right sidebar was the only
consumer left that did not route through useI18n(), so en-US users kept
seeing Chinese chrome.

Thread every label through useI18n(), including the close-button aria-label
(common.settings.close, newly added to both dictionaries). Themes and
primaryColors are moved into the component body so the t() call can resolve
at render time, matching how cool-admin threads translations through
component-local configuration arrays.
