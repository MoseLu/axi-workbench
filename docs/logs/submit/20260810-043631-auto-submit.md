  interpolating API.

Test the OneTimeCodeInput by mocking useI18n with a tiny zh-CN
dictionary in OneTimeCodeInput.test.tsx; the existing aria-label
assertions stay valid verbatim and the test no longer needs a real
I18nProvider wrapper.
