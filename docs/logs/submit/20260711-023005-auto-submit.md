## Commit Body

Adds idempotency replay and a uniform audit event for every mobile write so a flaky cellular network cannot double-charge a job or approval, and every mobile action leaves a single self-describing trail in cacheDir/audit.jsonl.

services/control-plane/src/idempotency.mjs (new, ~110 lines, 0 npm deps):
- createIdempotencyService({ cacheDir, ttlSeconds = 86400 }).
- check({ deviceId, key }) -> { cached: true, response } OR { cached: false }.
- record({ deviceId, key, response }) -> { ok: true } — atomic writeFileSync with mode 0o600; chmod 600 best-effort; missing/corrupt/expired files are treated as cache misses (TTL 24h).
- Keys validated against /^[A-Za-z0-9_-]{8,128}$/; deviceIds validated against /^dev_[A-Za-z0-9_-]{6,}$/. Persistence layout: cacheDir/idempotency/<deviceId>/<key>.json.
- _internals exposed for tests.

services/control-plane/src/control-plane.mjs:
- Imports createIdempotencyService and exposes it as controlPlane.idempotency.
- Exports recordMobileAudit({ cacheDir, event }) — appends a single mobile_action entry to cacheDir/audit.jsonl with normalised fields: { auditKind: 'mobile_action', deviceId, idempotencyKey, projectId, actionType, approvalRef, status, occurredAt }. Missing fields land as null so the ledger is always self-describing. chmod 600 on first write; existing files keep their permissions.
- createControlPlane() now returns idempotency and recordMobileAudit alongside the existing surface.

services/control-plane/src/server.mjs:
- Adds validateMobileAction(body, requiredFields) — fail-fast field-presence check returning { ok, error }; the three POST handlers now call it with their respective required sets:
    /jobs                 -> idempotencyKey, projectId, actionType
    /jobs/:id/cancel      -> idempotencyKey, projectId, actionType
    /approvals/:id/decision -> idempotencyKey, projectId, actionType, approvalRef
- Each handler consults controlPlane.idempotency.check() first; on hit, it serializes the cached response verbatim and sets X-Idempotency-Replay: true. On miss, the control-plane action runs and the response is recorded for replay.
- After every executed or replayed response, controlPlane.recordMobileAudit() writes the six fields into cacheDir/audit.jsonl. Device identity comes from the pairing token (or the static-owner-token fallback); no client-supplied deviceId is ever trusted.
