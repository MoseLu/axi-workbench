## Commit Body

The workbench Layout css and tokens layer used a private --mpms-*
alias layer that pointed at --axi-layout-* / --axi-* tokens
(see apps/workbench/src/styles/tokens.css). The alias layer added
an indirection without semantic value, and any new code reaching
for layout tokens would naturally gravitate to --axi-layout-*
rather than --mpms-*.

Migrate 30+ call sites in 5 Layout css files from --mpms-* to the
canonical --axi-layout-* / --axi-* targets:
