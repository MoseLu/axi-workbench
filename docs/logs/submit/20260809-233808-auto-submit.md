fix(workbench-mobile): wrap bare hex colors in design-token fallback

## Commit Body

workbench-mobile had bare hex literals in regular rule blocks
(color: #fff, background: #0c0c0c, etc.) on top of an already
partial var(--axi-*, #fallback) pattern. Wrap every literal in
var(--axi-*, #hex) so the design-token theme layer can take over
once the mobile app switches to dark/light themes; until then the
fallback keeps the current visual.

- Whites -> --axi-text-inverse
- Pages/surfaces -> --axi-bg-page / -bg-surface / -bg-elevated
- Text grays -> --axi-text / -text-muted
- WeChat brand green -> --axi-success / -success-bg
- Warning amber -> --axi-warning / -warning-bg
- Danger red -> --axi-danger
- Info blue / brand blue -> --axi-primary / -primary-hover
- Purple accents -> --axi-accent-magenta
- Sidebar gray -> --axi-bg-sidebar

Also covers the nested hex inside color-mix(... #hex ...).
