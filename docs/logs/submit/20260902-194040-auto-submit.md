M12 根因：之前 M8 commit 加的 objc2 msg_send 调 NSWindow 的
setShowsFullScreenButton:，但该 selector 在 NSWindow 上根本不存在
（macOS 13+ 仅 NSToolbar 上有）。msg_send 触发 Objective-C
method not found 异常，导致进程 abort（即便 catch_unwind 也来不及）。

结果：每次启动都崩，macOS dock 弹 unexpectedly quit 对话框。
用户截图的崩溃就是来源。

修法：删除 hide_fullscreen_button() 中的 objc2 msg_send 调用
保留函数为空体（占位），未来需要时可换用 NSWindowToolbar API
resizable:false + maximizable:false 已足够去掉 zoom + 最大化按钮；
macOS 13+ 全屏按钮需走 NSWindowToolbar 单独处理（本分支不做）
