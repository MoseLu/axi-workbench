apps/resource-orchestration/package.json
- @testing-library/jest-dom ^6.5.0 -> ^7.0.0. jest-dom 6.x
  ships a CJS vitest.js entry that calls expect.extend() in a

  API and restores the matcher registration side-effect.

apps/resource-orchestration/src/components/settings/SettingsDialog.tsx
- mask={{ closable: true }} -> maskClosable + mask. The
  antd Modal typings reject an object mask prop in current
  versions; the documented knobs are maskClosable and mask.

apps/resource-orchestration/src/gateway-client.ts
- GatewayProbeError constructor: super(message, options.cause ?
  { cause: options.cause } : undefined) -> super(message) +
  manual this.cause assignment. TypeScript 5.x Error constructor
  only accepts a single options argument (and even then does
  not surface cause); the second arg was a no-op at runtime
  but is a TS2554 error.

apps/resource-orchestration/src/App.test.tsx
- installFetch and collectRequestBodies parameters typed as
  `any` (eslint-disable line for the explicit any) so the
  vitest 4 MockInstance type does not collide between the
  installFetch signature and the call sites that pass
  `vi.fn().mockRejectedValue(...)` or `vi.fn((input, init)
  => ...)`. The runtime contracts are unchanged.

apps/resource-orchestration/src/hooks/useTheme.test.ts
- vi.spyOn(window, 'matchMedia') -> vi.stubGlobal('matchMedia',
  ...). jsdom does not implement window.matchMedia, so
  spyOn's precondition (existing function property) is
  unsatisfied. stubGlobal installs the property before use.

apps/resource-orchestration/src/gateway-client.test.ts
- The 'returns the default baseUrl when nothing is configured'
  case now accepts the .env.local-injected VITE_GATEWAY_BASE_URL
  (a gitignored LAN config used for phone-direct dev) when
  present, falling back to the documented DEFAULT_GATEWAY_BASE_URL
  otherwise. The assertion still pins the resolve order
  (override > env > default).

apps/resource-orchestration/tsconfig.json
- types: ['vitest/globals', '@testing-library/jest-dom'] so the
  jest-dom matcher types register on Assertion<T> and tsc sees
