# 多端能力归属与动作政策台账（基线与模板）

> 用途：任何新增或调整用户可见能力，在进入开发前都必须完成一条记录。它避免“两个端都做一遍”“没有端真正负责”，也避免仅凭手机/桌面尺寸判断动作是否可执行。

## 记录规则

- **位置**：标准或大型变更放在对应的 `docs/specs/<change-id>/CAPABILITY-OWNERSHIP.md`；小型变更可放在同目录 `TASK.md` 的“能力归属”小节，字段不可省略。
- **责任**：需求提出者填写；产品 Owner、领域 Owner 与目标端维护者共同复核。缺少记录的能力不得进入开发验收。
- **一条记录只对应一个领域能力**：若两个端都存在，必须写成不同的端侧任务和允许动作，不得以“同页适配”代替。
- **先定动作政策，再做按钮**：动作政策由领域 API/服务端授权实现，前端只渲染被允许的路径，不能自行扩大动作范围。

## 必填字段

| 字段 | 说明 |
| --- | --- |
| 能力与范围 | 名称、包含什么、不包含什么，以及关联领域对象。 |
| 任务角色与时机 | 谁在什么工作情境下使用，期望完成什么结果。 |
| 动作等级 | A 观察/提醒、B 受控单对象执行、C 管理/治理、D 专业/物理操作；说明归类理由。 |
| 执行表面 Owner | Web 控制中心 / Mobile 角色执行端 / 具体垂直工具；若双端，分别列出不同任务。Host 不是执行 Owner。 |
| Host / 发现入口 | 若通过 DevSvc 等 Host 发现或启动，记录 Host 与受控入口；不能以 Host 代替实际执行工具。 |
| 端侧允许动作 | 该端可查看、编辑、确认或批量处理的具体动作；禁止写“与 Web 一致”。 |
| 动作政策与授权 | 领域 API/服务端当前状态、权限检查、重验、二次确认、幂等与拒绝条件。 |
| 审计与关联 | 审计事件、业务对象标识；跨端时还要记录 `handoff correlation id`。 |
| 不支持端与交接 | 哪个端不做、为什么，以及如何携带对象、状态和上下文交接。 |
| 验收与回退 | 自动检查、浏览器/设备场景、失败提示、状态刷新与回退路径。 |
| 状态与复核 | Draft / Approved / Implemented；复核角色、日期和证据链接。 |

## 当前产品基线与已复核盘点

> 下表仍是规则与代表性能力的基线；当前 Web、Mobile 路由、按钮/写操作和专业入口的全量可审阅盘点已经记录在 [`CAPABILITY-INVENTORY.json`](./CAPABILITY-INVENTORY.json) 与 [`CAPABILITY-INVENTORY.md`](./CAPABILITY-INVENTORY.md)。它是 P0 的退出证据，并由 `pnpm check:capabilities` 在每次边界检查中复核。

| 能力 | 动作等级与执行表面 Owner | 允许动作与边界 | 不支持端 / 交接 |
| --- | --- | --- | --- |
| 租户、成员、RBAC、系统配置、批量处理、审计与导出 | C / Web | 完整后台管理，桌面级筛选、批量、确认和审计。 | Mobile 不做组织级配置、批量或全量审计；带对象和筛选上下文交接至 Web。 |
| 个人待办、告警、项目责任状态 | A + 部分 B / Mobile + Web | Mobile 处理本人和当前责任范围内的查看、回执和状态更新；Web 提供全量和规则配置。 | 需要跨项目比较、批量调整或复杂编辑时转 Web。 |
| 单对象受限确认 | B / Mobile + Web | Mobile 仅在对象、影响、责任和服务端状态可完整说明时执行；服务端再次鉴权、重验并记录审计。 | C 级批量、组织配置、权限变更或影响范围不清晰的动作仅在 Web。 |
| Web 运行状态与工作项 | A / Web | 从 Control Plane 投影跨项目查看、检索、筛选、分流并打开关联项目或交接。 | 不提供通用摄像头扫码；Mobile 只承接其自身受控审批确认。 |
| Mobile 审批扫码 | B / Mobile | 解析受控审批二维码并提交被授权确认；顶部 Scan 动作只覆盖该流程。 | 身份登录或设备配对必须以独立名称、入口与安全设计定义，不得自动并入该动作。 |
| 机器、设备、端口、进程、服务启停与诊断 | D / Fleet 等实际执行工具；DevSvc 为 Host/入口 | 在对应物理服务层实际执行工具完成，遵守其权限和审计。 | Web 提供状态、审计和受控入口；DevSvc 只发现/托管工具；Mobile 仅接收相关异常或被允许的确认。 |
