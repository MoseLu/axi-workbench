# 多端能力归属台账（基线与模板）

> 用途：任何新增或调整用户可见能力，在进入开发前都必须完成一条记录。它避免“两个端都做一遍”或“没有端真正负责”的产品漂移。

## 记录规则

- **位置**：标准或大型变更放在对应的 `docs/specs/<change-id>/CAPABILITY-OWNERSHIP.md`；小型变更可放在同目录 `TASK.md` 的“能力归属”小节，字段不可省略。
- **责任**：需求提出者填写；产品 Owner 与目标端维护者共同复核。缺少记录的能力不得进入开发验收。
- **一条记录只对应一个领域能力**：若两个端都存在，必须写成不同的端侧任务和允许动作，不得以“同页适配”代替。

## 必填字段

| 字段 | 说明 |
| --- | --- |
| 能力与范围 | 名称、包含什么、不包含什么。 |
| 所属表面 | Web / Mobile / Host / 垂直工具；若双端，分别列出。 |
| 用户与任务 | 谁在什么情境下使用，期望完成什么结果。 |
| 端侧允许动作 | 该端可查看、编辑、确认或批量处理的具体动作。 |
| 权威事实与授权 | 领域 API/服务端状态、权限检查和是否需要二次确认。 |
| 审计与关联 | 审计事件、业务对象标识；跨端时还要记录 handoff correlation id。 |
| 不支持端与交接 | 哪个端不做、为什么，以及如何携带对象与上下文交接。 |
| 验收 | 自动检查、浏览器/设备场景、失败与回退路径。 |
| 状态与复核 | Draft / Approved / Implemented；复核角色与日期。 |

## 当前产品基线

| 能力 | 所属表面 | 允许动作与边界 | 不支持端 / 交接 |
| --- | --- | --- | --- |
| 租户、成员、RBAC、系统配置、批量处理、审计与导出 | Web | 完整后台管理，桌面级筛选、批量、确认和审计。 | Mobile 不做组织级配置、批量或全量审计；带对象上下文交接至 Web。 |
| 个人待办、告警、项目责任状态 | Mobile + Web | Mobile 只处理本人和当前责任范围内的查看、回执、状态更新；Web 提供全量和规则配置。 | 需要跨项目比较、批量调整或复杂编辑时转 Web。 |
| 单对象受限确认 | Mobile + Web | Mobile 仅执行已预先授权、影响范围可在当前页完整说明的单对象确认；服务端再次鉴权并记录审计。 | 批量、组织级配置、权限变更、不可逆或影响范围不清晰的操作只能在 Web 处理。 |
| Web 通用扫码 | Web | 读取摄像头/图片、展示和处理结果；不默认产生审批授权。 | 不替代移动审批扫码。 |
| 移动审批扫码 | Mobile | 解析受控审批二维码并提交已授权确认；本期顶部 Scan 动作只覆盖该流程。 | 身份登录或设备配对必须以独立名称、入口与安全设计定义，不得自动并入该动作。 |
| 机器、设备、端口、进程、服务启停与诊断 | Fleet / DevSvc 等专用工具 | 在对应物理服务层工具完成，遵守其权限和审计。 | Web 只提供状态汇总、审计和受控入口；Mobile 仅接收相关异常或可确认动作。 |
