## 二、A 类：未提交文件批量 commit + push（按项目）

### 通用步骤

```bash
# 通用模板（每个项目替换 PROJECT 变量）
PROJECT=foundation/axi-rules  # 改成实际项目
cd /Volumes/code/workspace/$PROJECT

# 0. 确认状态（仅检查）
git status --short | head -5
git rev-list --count @{u}..HEAD

# 1. 先批量提交 .githooks 改动（独立 commit，避免污染业务 commit）
git add .githooks/
git commit -m "chore(githooks): sync workspace hooks

make workspace preflight read-only; sync post-commit hook from axi-rules.
Generated by audit-remediation-2026-09-25."

# 2. 再提交其他改动
git add -A
git commit -m "chore(audit-remediation): snapshot local changes (2026-09-25)

Frozen for review before batch push. See:
/Volumes/code/workspace/docs/state/audit-remediation-push-and-cleanup-2026-09-25.md"
```

```bash

# /Volumes/code/workspace/.DS_Store
# /Volumes/code/workspace/candidates/.DS_Store
# /Volumes/code/workspace/candidates/pelagic/.DS_Store

# 从各项目 git 索引移除（**不删工作树文件**）

echo ".DS_Store" >> /Volumes/code/workspace/.gitignore

# 提交
cd /Volumes/code/workspace
git -C candidates add .DS_Store .gitignore 2>/dev/null
git -C candidates/pelagic add .DS_Store 2>/dev/null
```
