# 迭代 / 特性 PRD 模板（L3 Sprint / Feature PRD Template）

> 使用说明：
> 1. 一次迭代或一个独立特性用一份；命名 `<项目id>-SPRINT-<日期或序号>`，放项目内 `docs/sprints/`。
> 2. 保持轻量，只回答"这次要解决什么、做哪些、不做哪些、怎么算完成"。
> 3. 完成后把结论回填项目 PRD / CHANGELOG / HANDOFF，本文件归档保留（不删除），作为决策与演进证据。
