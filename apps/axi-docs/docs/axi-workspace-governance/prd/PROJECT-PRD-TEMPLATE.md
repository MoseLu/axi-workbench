> 受约束规则：`foundation/axi-rules/rules/prd-format/AGENTS.md`
> 　- `AR-PRD-FORMAT-001`（P0）继承声明必填
> 　- `AR-PRD-FORMAT-002`（P1）§2 分层理念必填
> 　- `AR-PRD-FORMAT-003`（P1）FR 必须含量化锚点
> 　- `AR-PRD-FORMAT-004`（P1）多模块必须含"整合 X"收口 FR
> 　- `AR-PRD-FORMAT-005`（P2）模板升版触发继承者迁移
>
> 使用说明：
> 1. 把本文件原样**复制**到项目仓库根目录（命名 `PRD.md` 或 `docs/PRD.md`）；不要手抄段落，保证结构性继承。
> 2. 复制后**保留文首元信息块**的 `template_version: v1.1` 与 `inherits: docs/prd/templates/PROJECT-PRD-TEMPLATE.md` 两行（AR-PRD-FORMAT-001）。
> 3. 把所有 `{{占位符}}` 替换为真实内容；用不到的章节可删除，但**§1 一句话定位、§2 分层理念、§6 FR、§10 AC、§11 验证命令、§12 未决项不可省**。
> 4. 需求用可验证的陈述句写，编号 `FR-x` / `AC-x`；优先级 `P0/P1/P2`；每条 FR **必须**含数字阈值 / 结构计数 / 外部标准引用（AR-PRD-FORMAT-003）。
> 5. 多模块项目（§7.1 列 ≥2 个模块）必须在 FR 表最后一条加"整合 X"收口 FR（AR-PRD-FORMAT-004）。
> 6. 同一条信息只在 PRD 维护一份；"怎么跑命令"放 `README.md` / `TDD.md` / `AGENTS.md`，此处只引用；"为什么"放 `ADR`，此处只放摘要。
> 7. 完成后到 `docs/prd/README.md` 索引登记编号、位置、状态、模板版本与最后更新时间。
