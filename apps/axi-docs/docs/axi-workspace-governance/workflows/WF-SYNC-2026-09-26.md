## 经验教训（给未来 agent）

1. **"中间态 ≠ 完成"** 在 8 子代理场景下被反复验证：每个子代理必须报告"文件已写入 + 字节数 + 3 条关键决策"，不能仅说"已完成"

3. **AR-GIT-010 守门实战**：7 个 commit 每个都有完整 lore trailer，比之前的 `batch-snapshot-dirty` 21 commit 模板化更扎实；关键是 stage 阶段必须**只看本次新增文件**
