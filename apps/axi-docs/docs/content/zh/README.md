# Axi Docs 中文内容

本目录是 Axi Docs 的简体中文翻译树。

## 章节

- `guide/` 包含映射到 `/zh/guide/*` 的公共指南页面。
- `plans/` 包含长期“想法到落地”方案与方案契约。
- `projects/` 包含工作区项目档案。

在创建英文翻译时，请在 `../en/` 下使用相同的相对路径。

方案是知识记录，不是任务队列。执行工作应链接到 Axi Todo，而不是把任务状态复制进方案页。
