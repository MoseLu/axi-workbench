## 技能库是什么

技能库把 Axi Skills 中的 `SKILL.md` 和支持文档索引为可阅读页面。每个条目描述一种可复用能力、适用场景、执行流程和约束。

## 选择语言

英文来源使用 `axi-skills`，中文镜像使用 `axi-skills-zh`。进入 `/zh/skills` 时优先选择中文来源；进入 `/en/skills` 时使用英文来源，不会静默混用另一种语言。

## 浏览分组

左侧侧栏按能力分组和子分组展示技能。分组默认折叠，展开后可以查看完整条目列表；打开文档后，侧栏仍保留完整目录，便于连续阅读。

## 搜索技能

不知道技能属于哪个分组时，直接使用全局搜索。技能标题、描述、路径、标签和正文都可参与匹配。
