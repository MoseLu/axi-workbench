# Axi File Preview (xlsx Dedup-Audit Viewer + Custom VideoPlayer)

> 权威来源:`/Volumes/code/workspace/candidates/axi-file-preview/`。
> Partition:`candidates/`。Branch:`feature/ci-check-design-tokens-entry`。
> Lifecycle:`prototype`。Owner:libu。

## Summary

Axi File Preview 是一个自包含的本地 web 工具,用于摄入 dedup-audit
`audit.json`(由外部 `daily dedup` 脚本在 macOS 上扫描两个外部卷时产出),
并将重复组渲染为三个可搜索的 tab(图片 / 视频 / 加密 .ts)。UI 是基于
`@axi/core` / `@axi/crud` / `@axi/tokens` 包(`link:` 协议指向
`foundation/axi-ui/packages/*`)的 Ant Design 6.6 + React 19 + Vite 5.4 SPA,
单文件 React 入口 `src/App.tsx` 内含三个子组件 —— `ThumbCell`、`DetailModal`
以及核心组件 `VideoPlayer` —— 加一个在缩略图点击时打开的 `Lightbox`。
xlsx-report-renderer 这一角色 **不** 是一个 parser;繁重的工作由外部脚
本(`audit.json` 的产出方)完成,本工具只是摄入 JSON,按行拆分到 `img /
vid / ts` 桶中,并通过 `AxiTable` 进行实时过滤与分页。

自定义 `VideoPlayer` 是一个 700 行的 React 组件,故意复刻原生 `<video>`
的功能面(play / pause / 纵向音量弹出 / 0.5×–2× 速率菜单 / 全屏 / 原生
PiP / 带 `x.com` 品牌化的 Document Picture-in-Picture / 键盘快捷键 / 自动
转码回退)。它是未来向 `@axi/ui/packages/widgets` 贡献的候选。媒体字节流
由自定义 Vite middleware `serve-local-volume` 提供,暴露
`/__local/<encodedPath>` 与 `/__transcode/<encodedPath>` 给严格位于
`/Volumes/` 之下的路径 —— middleware 拒绝该前缀之外的任何路径,并提供 HTTP
`Accept-Ranges` 字节;当遇到 `MEDIA_ERR_SRC_NOT_SUPPORTED` 时,player 自动
切换到 `__transcode` 路由,该路由派生 `ffmpeg`(libx264 veryfast + AAC +
faststart),结果存入以 `sha256(realpath + size + mtimeMs)` 为 key 的 tmpdir
缓存。

渲染器表面对 audit 数据与磁盘是只读的。该工具是 **loopback-only**
(`host: 127.0.0.1`,`strictPort: 5183`),因为文件系统 middleware 没有认证机
制,`AGENTS.md` 与 `README.md` 都明确 dev server 不得暴露到 LAN。晋升至
`products/` 需要按 `TASK.md` P3 进行 `project-maturity-v1` 审核。

## Architecture Highlights

**Single-page React app、3 个 tab、按组的 detail modal。**`App.tsx` 在 mount
时获取一次 `./audit.json`,然后基于 `keep` 字段的文件扩展名记忆化三组平铺
行桶(`img / vid / ts`)。`bucketOf(g)` 在路径匹配 `.ts` 或 `.d.mts` 时返
回 `'ts'`(后者被排除在视频桶之外,因为 audit pipeline 把源码目录下的
TypeScript 模块声明以 `*.d.mts` 报告)。每个 tab 通过 `AxiTable<any>` 渲
列,列为 `[id, 缩略图 (ThumbCell), 重复次数, 源文件路径 (mono), 详情]`。
实时搜索按 content / path / decision 过滤,或在 query 完全为数字时按
`idx` 过滤。表格使用 `storageKey: "dedup-audit-<tab>"`,以便列可见性跨
tab 持久化。Per-tab 分页位于 `pageSizeByTab`,以保证 50 / 50 / 50 在各 tab
之间相互独立。「详情」 按钮打开 `DetailModal`,呈现 keep 行与 cleanup 列
表,都只是路径(不打开 lightbox) —— 实际的媒体查看通过 lightbox 进行。

**Lightbox = image / video / `.ts` 统一轮播。**`Lightbox({list})` 监听
`ThumbCell` 在点击时分发的 `open-lightbox` `CustomEvent`,在可见过滤后的
列表中找到匹配的缩略图,并根据情况渲染 `<VideoPlayer>`(当
`isVideoPath(cur.path)`)、`<img>`(当 `IMG_EXT`)或 "加密 .ts 切片无法播
放" 占位(当 `isTsPath(cur.path)`)。`computeOptimal(w, h)` helper 在视频
纵横比与视口纵横比相反时将视频旋转 90°;`cycleRotate()` 可由用户覆写。
prev / next 导航使用 `pointerdown`(不只是 `click`),使按下动画居中且
视频/背景无法吞噬事件。方向键也参与导航。标题(`lb-info`)使用
`wrapHover || isPaused` 进行淡入淡出 —— 永不永久遮挡视频。

**Custom VideoPlayer 与原生对等。**`VideoPlayer({path, poster, rotation,
onLoadedMeta, onClick, onHoverChange, onPausedChange})` 自有
`HTMLVideoElement` ref + 一个 wrapper ref。State:`playing`、`t`、`dur`、
`vol`(0–1,持久化于 `axi-file-preview:player-volume`)、`muted`(持久化于
`axi-file-preview:player-muted`)、`rate`、`hovering`、`loading`、`error`、
`sourceUrl`、`isFs`、`isPip`、`volHover`、`rateOpen`。Refs:`seekingRef`、
`hideTimerRef`、`pipWindowRef`、`pipParentRef`、`pipNextSiblingRef`。错误
路径在第一次 `__local` URL 返回 `MEDIA_ERR_SRC_NOT_SUPPORTED` 时自动回退
到 `/__transcode/<encodedPath>`。Picture-in-Picture 有两条路径:(a) 原生
`<video>.requestPictureInPicture()`,(b) Chrome Document PiP,通过
`window.documentPictureInPicture.requestWindow({width:520,height:320})`,
将每个 `<link rel="stylesheet">` 与 `<style>` 克隆到新窗口,在那里追加
player DOM 节点、设置 `x.com` 品牌,并在 `pagehide` 时把节点恢复到原位。
音量是一个向上弹起的物理装置(`writing-mode: vertical-lr`,32×110,半透明
+ 12 px blur),锚定到一个 36×36 的按钮。键盘:`Space/k` 切换、`m` 静音、
`f` 全屏、`p` PiP、`←/j` 后退 −5/−10s、`→/l` 前进 +5/+10s、`↑/↓` 音量 ±0.05。

**`serve-local-volume` middleware 作为安全边界。**`configureServer` 中挂
载两条路由:`/__local`(原始字节流)与 `/__transcode`(ffmpeg 转码后的 mp4)。
两者都调用 `resolveVolumeFile`,它解码 URL,拒绝 `..` 或任何不以
`/Volumes/` 开头的路径,realpath 后再次检查前缀,并 `stat` 确认是文件。
`sendFile` 设置 `Accept-Ranges: bytes`,解析 `Range: bytes=start-end`,并
以 `206` 返回请求的字节区间。转码缓存以 `sha256(realpath + size + mtimeMs)`
为 key,持久化在 `os.tmpdir()/axi-file-preview-transcode/`。并发的转码请
求共享同一 Promise(`transcodeJobs: Map<output, Promise>`),因此两个 tab
请求同一个 `.avi` 只会派生一个 `ffmpeg`。ffmpeg 命令为
`-c:v libx264 -preset veryfast -pix_fmt yuv420p -c:a aac -b:a 128k
-movflags +faststart`,临时文件成功后重命名到位。MIME 表覆盖 mp4 / m4v
/ mov / webm / mkv / avi / wmv / flv / mpg / mpeg / 3gp / mts / jpg / jpeg
/ png / gif / webp / bmp / heic / ico / ts。

**Audit schema 作为数据合同。**`audit.json` 是一个
`{stats: {imgTotal, vidTotal, tsTotal}, groups: [{keep: RowData | null,
cleanup: RowData[]}]}` 文档(依据 `docs/HANDOFF.md` 是 schema v1)。
`RowData` 是 `{r, id, content, count: "×9", path: "/Volumes/.../...", note,
image: "group-001/foo.jpg" | null}`。`previewLabel(content)` helper 在
显示标签中去掉尾部 `· 8-char-hex` dedup hash,同时保留在数据模型中
—— 2026-09-28 按 `CHANGE.md` 添加。

**`@axi/*` link 依赖与 design-token 规范。**四个 `@axi/*` 包通过绝对路径
链接到 `foundation/axi-ui/packages/*`,因此项目无需版本钉即可获得 Axi
设计系统的本地开发版本。两个 pnpm 脚本 (`check:design-tokens`、
`check:ui-aesthetic`) 调用 `foundation/axi-ui/scripts/*` 来强制设计系统。
最近的 git 历史由 icon-system 规范化主导(Picture / Video / Lock 内联
SVG、补充的 fullscreen icon 路径、X 风格 32×32 hitbox、20×20 icon 框、
纵向音量舱、速率菜单模糊)。
