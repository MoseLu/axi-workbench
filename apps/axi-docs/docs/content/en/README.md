# Axi Docs English Content

This locale tree contains the English source documentation.

## Sections

- `guide/` contains the public guide pages that map to `/en/guide/*`.
- `plans/` contains durable idea-to-landing plans and plan contracts.
- `projects/` contains workspace project dossiers.

Use the same relative paths in `../zh/` when creating Simplified Chinese translations.

Plans are knowledge records, not task queues. Link execution work to Axi Todo instead of copying task status into plan pages.
