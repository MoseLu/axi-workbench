## What the library contains

The Skills set indexes `SKILL.md` files and supporting documents from Axi Skills. Each entry describes a reusable capability, its use cases, workflow, and constraints.

## Locale selection

English uses `axi-skills`; Chinese uses `axi-skills-zh`. `/en/skills` selects the English source and `/zh/skills` prefers the localized source without silently mixing languages.

## Browse groups

The left sidebar groups skills by capability and subsection. Groups begin collapsed, preserve the full list when a document opens, and support continuous reading across entries.

## Search skills

Use global search when the capability group is unknown. Skill titles, descriptions, paths, tags, and body content participate in matching.
