## Open search

Click the search control or press `⌘K`. Suggestions include documents and tags; submitting a query opens the result page for the active locale.

## Match scope

Search combines title, description, path, tags, and body content. Results cover enabled Guide, Skills, Workspace, and other searchable sources, and include the source and path.

## Improve discovery

- Write specific `title` and `description` values.
- State the problem, purpose, and boundary near the beginning.
- Reuse a small set of stable tags.
- Do not place essential information only inside screenshots.

## View results

After a search is submitted, this page displays matching documents below the guide content. Selecting a result opens its document page.
