## Summary

`axi-rules` is the **local constraint + SOP layer for Axi agents** and the
**first local authority** after system / developer / direct user instructions.
It is intentionally explicit so weaker local agents (Claude Code CLI /
MiniMax M3) can proceed without guessing. The repository is a **declarative
documentation and indexing system, not a runtime rules engine** — rules are
Markdown documents consumed by agents at startup and by bridge/RAG consumers
in Codex Plus, Feishu, and cc-connect.

The corpus is organised as **13 category modules** under `rules/*/`, each
with a top-level `AGENTS.md` and one `AR-XXX-NNN` (or `AR-XXX-YYY-NNN`) rule
file per rule. Categories cover agent-routing, memory, verification, safety,
routing, change, handoff, lifecycle, project-bootstrap, development-sop,
git-automation, cicd, codex-tooling, prd-format (v1.1+), workspace-discovery
(2026-06+). Every category has an `AGENTS.md` that explicitly references
`.claude/ARCHITECTURE.md` and is enforced by
`scripts/guard-all-categories-have-agents-md.py`.

Three **machine-readable indexes** in `index/` are generated by
`scripts/build-index.py` (3,587 LOC) and validated by
`scripts/validate-index.py` (900 LOC, ≥ 12 rules hard-check, schema v2):
`index/projects.json` (canonical workspace project routing mirror,
`axi-rules.project-index.v2`), `index/rules.json`
(`axi-rules.rule-index.v2`, 173 rules, generated bundle hash `1d32df6f…`),
`index/sources.json` (`axi-rules.sources.v1` — rank 1–5 precedence chain).
`index/fallbacks.md` and `index/task-execution-routing.v1.json` complete the
contract; the routing policy is generated deterministically by
`scripts/task_execution_routing.py:policy_document()` (no model calls). A
`policy.bundle.json` artifact (158 KB, schema `policy.bundle/v1`,
`policyVersion=governance-policy/v1`) is emitted by
`scripts/build-policy-bundle.py` for the Guard Runtime in `axi-agent`.

A React + three.js visualization (`frontend/`) demos the memory-recall
pipeline; verification covers `pnpm --dir frontend typecheck`,
`pnpm --dir frontend test`, `pnpm --dir frontend build`, plus
`pnpm --dir frontend e2e`. The single combined entry point is
`make rules` (`rules-build` + `rules-validate` + `rules-guard`).

The handoff workflow is gated by `scripts/handoff-workflow.py`
(AR-HANDOFF-004 mechanical gate; 864 LOC) and the Claude PreToolUse hard
block (`scripts/hooks/claude-pretool-edit-gate.py` installed via
`scripts/install-handoff-edit-gate.py`). The
`scripts/test-claude-noninteractive.py` weak-prompt regression tests an
end-to-end agent handover against external assertions (738 LOC); the
`--prepare-only` mode is **diagnostic-only** and must never be cited as a
full pass.

## Architecture Highlights

**Four-layer model (PRD §2 / `.claude/ARCHITECTURE.md`).** L0 generated
indexes (`index/*.json`, `policy.bundle.json`, `index/task-execution-routing.v1.json`)
are the machine-readable source; L1 rule documents (`rules/<cat>/AR-*.md`)
are the human-readable fact source; L2 category modules
(`rules/<cat>/AGENTS.md`) are the semantic boundary that owns exactly one
category; L3 entrypoints (`INDEX.md`, `AGENTS.md`, `README.md`, `Makefile`)
are the agent + human entry contract. Dependency is single-direction
**L3 → L2 → L1 → L0**; reverse reference = index drift.

**Generated indexes, not hand-edited.** `scripts/build-index.py` is the
single source of index regeneration; it walks the 9 workspace partitions
(`foundation`, `workbench`, `agent-cluster`, `products`, `candidates`,
`distributions`, `tools`, `references`, `archive`), applies
`PROJECT_OVERRIDES` for `axi-rules` and other curated entries, parses each
project's documentation entrypoints (`AGENTS.md`, `README.md`, `INDEX.md`,
`TODO.md`, `MILESTONE.md`, `PRD.md`, `TDD.md`, `.claude/PARADIGM.md`,
`.claude/ARCHITECTURE.md`), and emits `index/projects.json`,
`index/rules.json`, `index/sources.json`, `index/docs-source.json`, plus
Markdown mirrors. `EXCLUDED_NAMES` carries `.omx`, `.git`, caches,
`node_modules`, `__pycache__`, `downloadtemp`, `codex-plus-app`,
`photo-sort-*`, etc. `DOC_ENTRYPOINTS_REQUIRED = (AGENTS.md, README.md,
INDEX.md)`. Per-project overrides for `axi-rules` declare its stack
(`Markdown, JSON, Python, React, TypeScript, Vite, three.js`) and
verification matrix (`validate-index.py`, `pnpm --dir frontend test/
typecheck/build`).

**Rule Compiler (`policy.bundle.json`).** `scripts/build-policy-bundle.py`
walks `rules/*/AR-*.md` (parses YAML frontmatter, falls back to
`# AR-XXX-NNN` Markdown heading for 9 known legacy verification files
listed in `KNOWN_MISSING_FRONTMATTER_IDS`), then walks `rules/*/AGENTS.md`
for `### AR-*` inline headings, and emits one rule per ID into
`policy.bundle.json` (schema `policy.bundle/v1`,
`policyVersion=governance-policy/v1`, `compilerVersion=1.0.0`). The bundle
content hash is `sha256(json.dumps(payload_without_hash,
sort_keys=True, ensure_ascii=False))`; `bundleId` and `compiledAt` live
outside the hashed payload so two consecutive rebuilds against the same
corpus always produce the same hash. `CATEGORY_PRECEDENCE` orders Guard
Runtime evaluation (safety > routing > agent-routing > git-automation >
cicd > handoff > lifecycle > verification > memory > project-bootstrap >
development-sop > prd-format > project-display > codex-tooling > workflow
> change > fallback > bridge). Default effect for safety category is
`deny`; everything else defaults to `allow`. The 10-case
`policy-bundle-contract.test.mjs` Node `--test` suite asserts determinism
across rebuilds, rule shape, sort precedence, id uniqueness, missing-
frontmatter list match (9 known legacy), and inline-rule counts per module.
First emitted artifact: 173 rules; bundleHash
`1d32df6fa85249363f45bbe96d967138ec352f72e38ade13604d0174f2140cb5`.

**Source precedence (rank 1–5).** `index/sources.json` declares
`axi-rules.sources.v1`: rank 1 = `system_developer_user` (purpose:
"non-local instructions + current user intent"); rank 2 = `axi-rules`
("local agent constraints, project routing, memory, verification,
safety"); rank 3 = `local-codex-memory` ("continuity, durable
preferences, prior decisions"); rank 4 = `axi-docs` ("fallback
documentation when axi-rules has no answer"); rank 5 =
`live-workspace-inspection` ("current-state verification when indexes
or docs are stale"). `bridge_rag.exclude_runtime_dirs` mirrors
`EXCLUDED_NAMES`; `prefer_json_namespaces: ["axi-rules-index"]`;
`semantic_markdown_namespaces: ["axi-rules", "codex-memory", "axi-docs"]`;
`fallback_namespace: "axi-docs"`. The `workspace_handoff` block carries
`defaultLocalPath=/Volumes/code/workspace/.workspace/project-handoff.json`,
`expectedMaxAgeHours=168` (7 days), `localPathEnv=AXI_WORKSPACE_HANDOFF_PATH`,
`schemaVersion=2026-06-11`,
`validationCommand="python3 /Volumes/code/workspace/scripts/workspace-project handoff --json > {path} && python3 scripts/validate-index.py"`.

**Task-execution-routing v1 (workflow-first, Agent as bounded executor).**
`scripts/task_execution_routing.py:policy_document()` is the deterministic
source for `index/task-execution-routing.v1.json`. Routes: `workflow`
(`path_enumerable=True` → `enumerable_path` reasonCode, allows
`fixed_workflow_steps`); `bounded_agent`
(`local_path_unenumerable=True AND read_only=True` →
`read_only_open_exploration`, allows allowlisted read-only tools +
sandbox + bounded budget); `escalate` (any `requests_command /
requests_write / requests_external_side_effect /
requests_privilege_escalation` → `command_requested /
write_requested / external_side_effect_requested /
privilege_escalation_requested` reason codes; fallback
`unknown_request`). `control_flow_owner: "workflow-engine"` —
**the workflow engine owns the route, not a model or Agent runtime**.
Linked from `AR-ROUTING-006` in `rules/agent-routing/AGENTS.md`.

**Handoff workflow mechanical gate (AR-HANDOFF-004).**
`scripts/handoff-workflow.py` runs the 9-step gate and emits
`HANDOFF_PACKET` with `ok` + `edit_allowed`. The Claude PreToolUse hook
(`scripts/hooks/claude-pretool-edit-gate.py`) is installed via
`scripts/install-handoff-edit-gate.py` and wired into the workspace
`.claude/settings.json`. `python3 scripts/handoff-workflow.py --require-edit-allowed`
hard-blocks Write/Edit for unauthorised project ids.
`scripts/test-handoff-workflow.py --self-test` covers allow/deny paths.

**Memory-source-precedence vs project-level scope.** The repository
distinguishes between "axi-rules answer" (rank 2 — must be cited in
bridge replies per `AR-ROUTING-002`) and "bridge / RAG consumer" (rank 1
through 5, encoded in `index/sources.json`). `axi-docs` is **fallback
rank 4 only** — never used to override an `axi-rules` answer.

**Tool / command boundaries.** `.claude/PARADIGM.md § Tool / Command
Boundaries` lists deny / confirm lists. Deny (never run even with
explicit user confirmation): recursive deletion of `/`, `~`,
`$WORKSPACE_ROOT`, `.git`; `git push --force` to `main` / `master` /
release branch; `chmod -R 777`; `chown -R` outside sandbox;
`curl | sh` / `wget | bash` of unverified URLs; `DROP DATABASE /
DROP TABLE` on non-scratch DBs; `kill -9 1`; `mkfs`; raw `dd` to a
device; `eval $(...)` of untrusted input. Confirm (run only after
`AskUserQuestion` returns explicit yes): `git rebase -i`; `git reset
--hard`; `git clean -fd` / `git clean -fdx`; `git push
--force-with-lease` to a feature branch; Write that overwrites tracked
file outside `axi-rules/`; HTTP `POST/PUT/DELETE/PATCH` against external
service; any deploy or publish. Full rationale per-command lives in
`rules/safety/AGENTS.md#ar-safety-002--tool--command-boundaries`.

**Change protocol (AR-CHANGE-001).** Every commit that changes
agent-visible behavior, workflow, or validation must update **both**
`CHANGE.md` under `## Unreleased` (root, development-facing) and the
nearest feature/module-level `CHANGE.md` (e.g. `frontend/CHANGE.md` for
frontend changes). The single-line commit message
"Update CHANGE.md per AR-CHANGE-001" is sufficient.

**13 category modules.** Each module owns exactly one category; the
L2 contract is enforced by `scripts/guard-all-categories-have-agents-md.py`.
Category names that already map in `PARTITION_BY_CATEGORY`:
`agent-routing`, `memory`, `verification`, `safety`, `routing`,
`change`, `handoff`, `lifecycle`, `project-bootstrap`,
`development-sop`, `git-automation`, `cicd`, `codex-tooling`,
`prd-format`. `workspace-discovery` was added in 2026-06.

## Notes

`axi-rules` is the workspace rule index + memory-source-precedence + task-routing policy v1. The repository is declarative Markdown rules + 13 category modules (`rules/*/`) + 3 generated JSON indexes (`index/projects.json`, `index/rules.json`, `index/sources.json`, schema v2), not a runtime rules engine. `scripts/build-index.py` (3,587 LOC) + `scripts/validate-index.py` (900 LOC) validate schema v2 with ≥ 12 rules, ID cross-refs, and doc entrypoints. The Rule Compiler `scripts/build-policy-bundle.py` emits `policy.bundle.json` (158 KB; schema `policy.bundle/v1`; `policyVersion=governance-policy/v1`; bundleHash `1d32df6f…`, deterministic sha256); `scripts/policy-bundle-contract.test.mjs` (10 `node --test` cases) guards determinism, rule shape, sort precedence, and id uniqueness. `index/sources.json` declares 5 source-precedence ranks (`system_developer_user`, `axi-rules`, `local-codex-memory`, `axi-docs`, `live-workspace-inspection`); `index/task-execution-routing.v1.json` is generated deterministically by `scripts/task_execution_routing.py:policy_document()` and distinguishes `workflow` / `bounded_agent` / `escalate` routes, with control-flow owned by the workflow engine. `scripts/handoff-workflow.py` (AR-HANDOFF-004, 864 LOC) + Claude PreToolUse hook (`scripts/hooks/claude-pretool-edit-gate.py`) enforce a 9-step handoff mechanical gate; `scripts/test-claude-noninteractive.py` (738 LOC) is the weak-prompt regression, but `--prepare-only` is diagnostic-only. `make rules` is the unified entry (`rules-build` + `rules-validate` + `rules-guard`); rule/index/docs-only diffs should not trigger `pnpm --dir frontend typecheck/test/build`. Consumers per FR-7/AC-7: `axi-agent`, `axi-workbench`, `axi-coder`, `axi-feishu-codex-bridge`.
